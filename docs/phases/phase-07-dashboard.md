# Phase 07 — Interactive Dashboard

Status: **PLANNED**

## Objective
Design and implement the front-end user dashboard displaying family net worth, asset allocation, investment history, and individual member portfolio analytics.

## Why this phase exists
To make consolidated family mutual fund data usable, we need a visual interface that translates database metrics into interactive graphs, tables, and performance overviews.

## Scope
- Family-level summary dashboard.
- Individual member portfolio screens.
- Asset allocation visualizations (doughnut charts for Equity vs Debt, Sectoral, and AMC splits).
- Historical valuation timelines (line charts).
- Detailed folio and fund breakdown tables.

## Tasks
- [ ] Establish frontend technology framework (e.g. React/Next.js).
- [ ] Design mockups for responsive dashboard views.
- [ ] Integrate charting libraries (e.g. Chart.js, Recharts) for allocation and performance timeline renders.
- [ ] Bind dashboard views to backend API endpoints.

## Input
Valuation and analytics payloads from backend API endpoints.

## Output
An interactive web interface showing the family-level portfolio metrics.

## Validation
Ensure all tabular values matches overall aggregated summary cards exactly on screen.
